# Netflix Data Cleaning and Preprocessing

## About
This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Work Done
- Loaded and explored the Netflix dataset.
- Checked missing values and duplicate records.
- Handled missing values.
- Converted date and numeric columns into appropriate formats.
- Standardized categorical values.
- Created a feature for the year content was added.
- Exported the cleaned dataset as a CSV file.

## Output
The cleaned dataset is saved as `netflix_titles_cleaned.csv`.

## Dataset
[Netflix Movies and TV Shows Dataset – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
